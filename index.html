报告问题 / Report an issue

请通过邮件说明应用版本、设备和系统版本、复现步骤及报错信息。截图请遮挡私人聊天、密钥和其他敏感信息。不要发送 API Key。

Email the app version, device and OS version, steps to reproduce, and error message. Redact private conversations and sensitive details in screenshots. Never send API keys.

密钥与历史 / Keys and history

在设置中管理 AI 服务和密钥。iPhone 与 Mac 的历史和密钥不自动同步。导出的 JSON 文件可能包含私人对话，请谨慎分享。

Manage providers and keys in Settings. History and keys do not automatically sync between iPhone and Mac. Exported JSON files can contain private conversations; share with care.
